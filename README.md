# CatatUang

Aplikasi pencatat keuangan pribadi dan usaha. Simpel, cepat, dan bisa dipakai tanpa internet.

Versi 1.0.0 · Android 7.0 ke atas

---

## Fitur

### Catatan Harian
- Catat pemasukan dan pengeluaran hanya dengan beberapa ketukan
- Empat akun: Pribadi, Dagang, Tabungan, dan Investasi
- Saldo tiap akun tampil di bagian Dompet & Akun
- Pindah saldo antar akun
- Cari transaksi, serta filter berdasarkan akun dan jenis (pemasukan/pengeluaran)
- Edit dan hapus transaksi kapan saja

### Laba Dagang
- Laba bersih usaha dihitung otomatis dari akun Dagang
- Menampilkan omzet, modal/biaya, dan margin keuntungan
- Status untung atau rugi langsung terlihat
- Rekap per bulan dan filter bulan
- Riwayat transaksi khusus dagang

### Target Tabungan
- Buat target tabungan dengan nominal yang ingin dicapai
- Isi tabungan kapan saja, tersedia tombol cepat +50rb, +100rb, dan +500rb
- Pantau progres menuju target

### Data dan Pengaturan
- Export ke Excel (.xlsx), file tersimpan di folder Download
- Backup JSON dan Pulihkan Data untuk pindah HP atau berjaga-jaga
- Mode gelap dan terang
- Reset Data untuk mulai dari awal
- Data tersimpan di perangkat dan tidak dikirim ke server mana pun

## Cara Unduh APK di GitHub

### Cara 1: Dari Releases (disarankan)
1. Buka repository ini di GitHub.
2. Klik tab **Releases** (di sisi kanan halaman, atau di menu repository).
3. Pilih rilis paling atas (terbaru).
4. Di bagian **Assets**, klik **CatatUang.apk** untuk mengunduh.

### Cara 2: Dari Actions
1. Klik tab **Actions** di repository.
2. Pilih build **Build APK** terbaru yang bertanda centang hijau.
3. Gulir ke bagian **Artifacts**, lalu klik **CatatUang-APK**.
4. Ekstrak file zip yang terunduh, di dalamnya ada **CatatUang.apk**.

---

## Cara Install APK di HP

1. Pastikan file **CatatUang.apk** sudah ada di HP (cek folder Download).
2. Ketuk file tersebut untuk membukanya.
3. Jika muncul peringatan **"Instal dari sumber tidak dikenal"**:
   - Ketuk **Pengaturan**
   - Aktifkan **Izinkan dari sumber ini** untuk browser atau file manager yang kamu pakai
   - Kembali, lalu ketuk file APK lagi
4. Ketuk **Instal** dan tunggu sampai selesai.
5. Ketuk **Buka**, atau cari ikon **CatatUang** di layar utama.

Jika muncul pesan **"Aplikasi tidak terpasang"**, kemungkinan sudah ada CatatUang versi lama dengan tanda tangan berbeda. Backup data lewat menu Backup JSON, hapus (uninstall) aplikasi lama, lalu pasang lagi.

---

## Privasi

CatatUang tidak memerlukan akun dan tidak mengirim data keuanganmu ke mana pun. Semua catatan disimpan lokal di perangkat, jadi lakukan Backup JSON secara berkala.
