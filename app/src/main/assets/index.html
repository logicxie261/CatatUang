📖 Cara Penggunaan Aplikasi
1. Mencatat Pemasukan & Pengeluaran
  • Buka tab 📝 Catatan.
  • Pilih jenis transaksi: + Pemasukan atau - Pengeluaran.
  • Pilih akun yang sesuai (🏠 Pribadi, 🏪 Dagang, 💳 Tabungan, atau 📈 Investasi).
  • Isi keterangan transaksi, nominal, dan tanggal, lalu ketuk Simpan Transaksi.
2. Menghitung Laba Usaha (Khusus Dagang)
  • Pastikan setiap penjualan dan modal belanja usaha dicatat pada akun 🏪 Dagang.
  • Buka tab 🏪 Laba Dagang untuk melihat otomatis total Omzet, Modal/Biaya, Laba Bersih, dan Margin Keuntungan.
  • Gunakan filter bulan di pojok kanan kartu hijau untuk memantau laba per bulan.
3. Mengelola Target Tabungan
  • Buka tab 🎯 Tabungan untuk membuat target (misalnya Dana Darurat atau Beli Barang).
  • Ketuk tombol + Isi Tabungan pada target untuk menambah setoran. Setoran otomatis tercatat ke saldo akun 💳 Tabungan.
4. Mencatat Investasi
  • Saat menyetor dana atau membeli aset investasi, pilih + Pemasukan (untuk saldo masuk ke portofolio) atau - Pengeluaran (untuk penarikan/biaya) pada akun 📈 Investasi.
  • Catatan investasi terpisah dari Laba Dagang sehingga perhitungan untung rugi usaha tetap akurat.
5. Memindahkan Saldo Antar Akun
  • Di tab 📝 Catatan, ketuk tombol 🔄 Pindah Saldo pada kartu Dompet & Akun.
  • Pilih akun asal (misalnya dari Dagang ke Tabungan) dan masukkan nominalnya. Perpindahan ini tidak dihitung sebagai pengeluaran atau omzet baru.
6. Backup & Export Laporan
  • Semua data tersimpan otomatis di browser perangkat Anda.
  • Gunakan tombol 📊 Export Excel untuk mengunduh laporan tabel (.xlsx), atau ⬇️ Backup JSON untuk menyimpan file cadangan data agar aman saat ganti HP/browser.
